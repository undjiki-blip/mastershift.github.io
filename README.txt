WINNER MIND AGENCY — SITE ONE-PAGE

FICHIERS
- index.html : page unique avec toutes les sections et la navigation
- styles.css : design responsive, animations, effets et carte fluorescente
- script.js : menu mobile, année du footer et formulaire e-mail
- assets/hero-character.jpg : illustration de l’égérie affichée dans le Hero
- assets/reference-hero.png : capture de référence fournie

POUR VISUALISER
1. Décompressez le ZIP.
2. Conservez l’arborescence des fichiers.
3. Ouvrez index.html dans Chrome, Firefox ou Edge.

REMPLACER LA PHOTO DU HERO
Remplacez assets/hero-character.jpg par votre nouvelle image en gardant exactement ce nom. Pour déplacer ou agrandir le personnage, modifiez .visual et .visual img dans styles.css.

FORMULAIRE
Le formulaire prépare un message dans l’application e-mail (mailto). Il ne stocke pas les messages et n’envoie pas automatiquement les données à un serveur. Pour une réception en ligne, connecter un backend ou un service de formulaires.

AVANT PUBLICATION
Vérifiez l’adresse e-mail cible dans script.js et remplacez la note de portfolio par des réalisations réelles.
