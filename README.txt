WINNER MIND AGENCY — SITE MULTIPAGE
===================================

Fichiers :
- index.html : page d'accueil / hero
- about.html : qui sommes-nous
- services.html : services
- projects.html : projets (blocs exemples à remplacer par vos vrais projets)
- blog.html : journal (sujets éditoriaux proposés)
- contact.html : contact et formulaire
- styles.css : design responsive, animations et styles communs
- script.js : menu mobile, année automatique, formulaire email
- assets/hero-character.jpg : image du personnage utilisé dans le hero

Installation :
1. Gardez tous les fichiers dans le même dossier et le dossier assets à côté.
2. Ouvrez index.html dans un navigateur ou importez le dossier dans votre hébergeur.
3. Le site charge les polices Google Fonts avec connexion internet ; les polices système prennent le relais hors ligne.
4. Le formulaire de contact prépare un email à contact@mastershift.org dans l'application email de l'utilisateur.
5. Le bouton WhatsApp utilise le numéro +237 655 600 697.

Avant publication :
- Remplacez les blocs d'exemple de projects.html par des projets réels.
- Ajoutez les liens vers vos réseaux sociaux.
- Vérifiez l'email et le numéro WhatsApp de contact.
- Pour un formulaire envoyé directement en ligne, connectez un service de formulaire ou un backend.
